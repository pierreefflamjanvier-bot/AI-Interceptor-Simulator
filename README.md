# AI-Interceptor-Simulator
Ceci est un projet personnel pour monter en compétence sur mes connaissances comportementales des intercepteurs de drones.
L'objectif est de débuter par un modèle 2D, puis 3D, puis implémenter de la détection de cible sur flux vidéo avec ajustement de trajectoire.
A terme j'aimerai implémenter de l'IA pour rendre ce projet encore plsu pertinent.
